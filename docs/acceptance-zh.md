# Quiet Insights 本地验收

验收版本日期：2026-09-28。仅本地运行，尚未发布 GitHub。

## 打开与操作

地址：http://127.0.0.1:4182/。右上角切换中文。

1. 选择 Acceptance Studio，可查看已写入的 56 条示例事件、10 台匿名设备、14 个会话。
2. 概览中选择版本 1.1.0 并应用，结果为 20 条事件；切回所有版本后恢复 56 条。
3. 转化漏斗中查看 Open to save：sample_opened → sample_viewed → sample_saved，每步 10 台设备。
4. 接入中创建自己的应用，保存显示的密钥。可添加示例事件，或从终端使用 HTTP 示例发送事件。
5. 事件页查看记录；概览右上角导出当前筛选条件的事件汇总 CSV。

示例流程为完整路径，因此每步都是 100%。自己的应用接入真实事件后，漏斗结果随上报数据变化。

## 使用边界

数据真实保存在本地 PostgreSQL，并非静态图表。当前是单机作品集版本：浏览器 Cookie 识别独立工作区，不含真实账号登录、成员权限或云部署。更换浏览器不会自动看到原工作区；请勿清除 Cookie。

界面默认英文，用户创建的应用名与事件名保持原文。每次分析最多读取 50,000 条匹配事件，超出时会提示缩小时间范围。数据保留期限为 7、30、90 天；缩短期限会删除超期事件。

## 后续启动

按 README 的本地数据库启动步骤启动数据库，再运行 `npm start`。修改源代码后应停止服务，重新构建，再启动。验收通过后再发布到 GitHub。
